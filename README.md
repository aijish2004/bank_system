# 🏦 Bank Management System

A simple and beginner-friendly **Bank Management System** built using Python.  
This project allows users to manage customer accounts and perform basic banking operations using Python file handling.

## ✨ Features

- 👤 Create customer accounts
- 🔍 Search customer/account details
- 💰 Check account balance
- 💵 Deposit money
- 💸 Withdraw money
- 📝 Update customer information
- 📂 Store customer data using files
- 🔐 Account number based customer management

## 🛠️ Technologies Used

- 🐍 Python
- 📁 File Handling
- 📦 OS Module
- 🎲 Random Module
- 🧠 Functions
- 📚 Dictionaries
